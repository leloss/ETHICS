# Code of Conduct  
  
We follow the Contributor Covenant v2.1.  
  
- Pledge: Provide a harassment‑free, inclusive experience.  
- Standards: Be respectful; accept constructive feedback; focus on what is best for the community.  
- Enforcement: Report incidents to {{COC_CONTACT_EMAIL}}. Maintainers will review and act in good faith.  
  
Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
